# Direction — Honest self-evaluation

**Question:** Can an agent judge its own output against reality, or does it
confabulate progress?

Current state: nothing. The Quality role in the Flow scenario is a stub; the
event log is ground truth the agent itself never reads.

Open problems: expected-vs-actual review cycles, verification tools that
aren't circular, and whether an agent that grades itself drifts upward. First
experiment: a review cycle that compares the agent's claimed actions against
the durable event log — the log as lie detector.
